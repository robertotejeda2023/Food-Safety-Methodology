## What is this?

A free, open-access food-safety governance kit for restaurants — logs, SOPs, and a checklist — to standardize sanitation, temperature control, and daily operations, and to help prepare for health audits.

Based on the FDA Food Code, the California Retail Food Code (CalCode), and ServSafe.

No sign-up. No cost. Free for any restaurant to use.

## How to use it

1. Download the files you need, in PDF or Word.
2. Print them and adapt them with your restaurant's logo.
3. Record daily — do not pre-sign entries, do not backdate, and do not sign for another employee.
4. Keep the completed records on file for your next health audit.

All documents are bilingual (English / Spanish).

## Files in this repository

| Code | Document | Format |
|------|----------|--------|
| FS-LOG-01 | Cold Storage Temperature Log | PDF |
| FS-LOG-02 | Daily Restroom Sanitation Log | PDF |
| FS-LOG-03 | Daily Sanitation Monitoring Record | PDF |
| FS-SOP-01 | Restroom Cleaning and Sanitization | PDF + Word |
| FS-SOP-02 | Cold Storage and Temperature Control | PDF + Word |
| FS-SOP-03 | 3-Compartment Sink Warewashing and Sanitization | PDF + Word |
| FS-SOP-04 | Cross-Contamination Prevention (also referenced as FSGF-SOP-003) | PDF + Word |
| FSGF-CHK-002 | 50-Point Sanitation Checklist | PDF + Word |

The 50-point checklist covers cold storage, restroom cleaning, 3-compartment sink warewashing, cross-contamination prevention, personal hygiene and food handling, and cleaning, verification and records. The pass threshold is **90% (at least 45 of 50 points)**.
