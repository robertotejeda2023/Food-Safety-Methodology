# Open Food Safety Governance Framework (OFSGF)

Developed by **Jose Roberto Tejeda Valdez**  
Food Safety & Human Development Specialist

## Overview
This repository contains open-access food safety monitoring logs, SOPs, and governance templates designed to standardize sanitation, temperature control, and operational procedures in food service environments.
